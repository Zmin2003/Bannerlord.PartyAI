# Party AI Controls Reforged - AI Commander CN

这是 `Party AI Controls Reforged` 的中文增强分支。它保留上游的家族部队、商队和驻军管理功能，并增加战场 AI 指挥官：AI 可以接管我方编队，你仍然亲自操作主角。

当前主要适配和验证目标为《Mount & Blade II: Bannerlord》`v1.5.2`。

## 主要功能

- 为家族部队、商队和驻军设置兵种模板、兵种比例、招募规则和行为限制。
- 为部队添加招募、巡逻、前往、护送、驻留、围攻和防守等命令队列。
- 自动管理招募、升级、买马、驻军和家族部队创建等大地图行为。
- 进入城市或村庄后按所选等级立即执行招募、升级、模板配兵和英雄换装。
- 自动生成 `v1.5.2` 全阵营最强模板及六个主文化的最优模板和推荐比例。
- 支持从 HTTPS JSON 地址导入社区模板，同时保留完整的玩家自定义模板编辑。
- 自动管理玩家家族城镇与城堡的建筑队列、每日项目和建设储备。
- 按稳定、经济、军事或均衡策略推荐或自动任命总督。
- 根据敌军威胁自动派遣家族部队驻守，抵达后可按限额补充驻军，并在安全后恢复原命令。
- 部署结束后，自动将玩家编队交给游戏原生战术 AI。
- 玩家始终保留主角控制权，可在战斗中随时收回或交还编队指挥权。
- 自适应野战 AI 按实际战力而非单纯人数选择战术，并在开战时显示双方人数和战力估算。
- 攻城时预测重型投石机、火焰投石机和配重投石机炮弹落点，让危险区内的空闲 AI 士兵短暂规避。
- 可按商队上限、精锐选项和金币保留额自动组建家族商队，并自动选择合适同伴和文化模板。
- 提供完整简体中文文本。
- 不修改单位生命、伤害、武器精度、移动速度或其他战斗数值。

## 安装

需要先安装并启用：

- [Bannerlord.Harmony](https://github.com/BUTR/Bannerlord.Harmony)
- [Bannerlord.UIExtenderEx](https://github.com/BUTR/Bannerlord.UIExtenderEx)

使用打包版本时：

1. 解压文件，将 `Modules/Bannerlord.PartyAI` 复制到游戏目录下的 `Modules` 文件夹。
2. 在启动器中依次启用 `Bannerlord.Harmony`、`Bannerlord.UIExtenderEx` 和 `Bannerlord.PartyAI`。
3. 启动单人游戏并载入存档。

不要同时安装同一模块 ID 的其他 Party AI Controls 版本。

## 使用方式

### 控制面板

载入战役存档后按 `Ctrl+P` 打开控制面板。这里可以：

- 设置默认的家族部队、商队和驻军规则。
- 编辑单独部队的兵种模板、构成比例、最高兵阶、自动招募比例和买马预算。
- 直接管理玩家主队，并为每支队伍选择定居点自动化等级。
- 设置是否允许加入军团、围城、劫掠、招募、捐赠驻军或俘虏领主。
- 添加和调整部队命令队列。
- 设置全局城镇管理规则，并为每个玩家封地单独覆盖策略、防务优先级和驻军目标。
- 修改所有相关快捷键。

如果快捷键设置错误导致面板无法打开，可在游戏控制台输入：

```text
partyai.open
```

### 定居点自动化

每支领主部队、商队和玩家主队可以分别选择：

- `关闭`：不在进入定居点时执行额外操作。
- `仅招募`：按模板和兵种比例招募当前可用兵员。
- `招募并升级`：在招募后自动使用已有经验、金币和所需物品完成可用升级。
- `完全自动`：再按模板转换不合适的兵种，并用队伍库存为 AI 领主及同队英雄换上更优装备。

普通士兵的装备由兵种定义决定，因此完全自动通过兵种升级树改善其装备，不会修改全局单位数据。主角本人的装备不会被自动替换。

### 城镇管理

城镇管理默认关闭。载入战役后，在 `Ctrl+P` 控制面板中打开“城镇管理”并主动启用；玩家家族拥有的城镇与城堡会显示在同一列表中，可分别编辑：

- `均衡`、`稳定`、`经济`、`军事`四种建设策略。
- 建筑队列、每日项目、忠诚与粮食紧急阈值。
- 建设储备目标、每日投入上限和玩家保留金币。
- 总督关闭、仅推荐或自动任命，以及跨城重分配冷却。
- 自动派防、防务优先级、目标防御战力和目标驻军人数。

自动派防只使用符合条件的玩家家族部队，不会拆散现有军团，也不会覆盖玩家主动下达的新命令。围城时可以动用最后的机动预备队；平时会保留设定数量的自由部队。启用自动补充驻军后，援军抵达安全定居点才会移交士兵，并同时遵守最大移交比例和部队最低留兵数。威胁解除且满足最短驻守时间后，系统恢复该部队原有命令与队列。

### 模板

载入战役时会根据当前游戏数据动态生成“全阵营最强”和各主文化最优模板；评分优先考虑兵阶及游戏计算的战斗力，因此不会依赖易失效的本地化兵种名称。

控制面板中的“在线模板”可导入 HTTPS JSON。格式示例见 [`template.example.json`](template.example.json)：

```json
{
  "name": "Imperial balanced elite",
  "troops": ["imperial_legionary", "imperial_palatine_guard"],
  "composition": {
    "infantry": 55,
    "ranged": 45,
    "cavalry": 0,
    "horseArcher": 0
  }
}
```

比例既可写成 `0-1` 小数，也可写成百分数；导入时会归一化。兵种使用游戏内部 `StringId`，无效 ID、重复名称、非 HTTPS 地址和超过 64 KB 的文件都会被拒绝。

### 大地图直接指挥

- 按 `Alt+X` 选择附近可直接指挥的部队。
- 按住 `Alt`，在地图上向已选择部队下达移动或目标命令。
- 默认快捷键可在 `Ctrl+P` 的模组选项中修改。

### 战场 AI 指挥官

- “自动战场指挥官”默认开启。
- 完成部署并正式开战后，AI 自动接管我方所有可指挥编队。
- 你仍然控制主角的移动、骑乘和战斗。
- 按 `Ctrl+M` 收回编队指挥权；再次按下可重新交给 AI。
- 快捷键和自动接管开关可在 `Ctrl+P` 的模组选项中修改。

“自适应野战 AI”不会再用固定高权重覆盖原生战术。它根据双方剩余战力、远程比例和兵种构成参与战术选择；弱势时原生防御战术仍可优先接管。人数接近并不代表战力接近，开战提示会显示按兵阶、装备和单位战斗力估算的实际比例。

“规避攻城火炮”只处理投石机、火焰弹、散射弹和配重投石机等重型范围弹药。它不会移动整支攻城编队，也不会打断正在近战、攀爬或操作攻城器械的士兵。

### 自动商队

在模组选项中启用“自动组建家族商队”后，玩家主队停留在未被围攻的非敌对城镇时，系统每天最多建立一支商队，直到达到所设上限：

- 建队费用与原生小型/精锐商队完全一致，并从玩家金币中支付。
- 支付后低于“保留金币”数值时不会建立商队。
- 自动从主队同伴中选择贸易、侦察和战术综合能力最高者。
- 新商队自动启用商队管理、完全自动，并优先采用当地文化最优模板。
- 同伴不足、金币不足或玩家不在安全城镇时会静默等待，不会强行创建。

## 兼容性说明

- 当前分支只针对游戏 `v1.5.2` 编译和验证。
- 战场接管只用于单人任务，不会在多人会话中加载。
- 此分支沿用原模块 ID `Bannerlord.PartyAI`，可覆盖更新原版，但不要并列安装两个版本。
