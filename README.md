# Party AI Controls Reforged - AI Commander CN

这是 `Party AI Controls Reforged` 的中文增强分支。它保留上游的家族部队、商队和驻军管理功能，增加了城镇管理、自动防御、战场 AI 指挥官，并在 2.0 版本完全重构了代码结构与界面，加入了统一的财政策略和工坊管理。

当前主要适配和验证目标为《Mount & Blade II: Bannerlord》`v1.5.2`。

## 主要功能

- 为家族部队、商队和驻军设置兵种模板、兵种比例、招募规则和行为限制。
- 为部队添加招募、巡逻、前往、护送、驻留、围攻和防守等命令队列。
- 自动管理招募、升级、买马、驻军和家族部队创建等大地图行为。
- 进入城市或村庄后按所选等级立即执行招募、升级、模板配兵和英雄换装。
- 自动生成 `v1.5.2` 全阵营最强模板及六个主文化的最优模板和推荐比例。
- 支持从 HTTPS JSON 地址导入社区模板，同时保留完整的玩家自定义模板编辑。
- 自动管理玩家家族城镇与城堡的建筑队列、每日项目和建设储备。
- 按稳定、经济、军事或均衡策略推荐或自动任命总督。
- 根据敌军威胁自动派遣家族部队驻守，抵达后可按限额补充驻军，并在安全后恢复原命令。
- **统一财政策略**：所有会花钱的自动化都受同一个金币储备和最低日收支约束，不再让玩家莫名亏钱。
- **工坊管理**：每日记录工坊资本，评估各城镇最适合的生产类型，亏损时推荐或自动转产，可一键出售，也能推荐或自动买入合适的工坊。
- **主队自动驾驭**：你不操作时，主队按自己的命令队列和待机命令行动（巡逻、招募、跟随等），点一下地图即可收回控制。
- **自动进攻与军团**：空闲家族部队明显强于附近敌方要塞时自动集结围城，加入王国后合并为一支军团。
- **进城自动出售**：进入城镇时按规则卖掉俘虏和战利品，锁定的物品和俘虏不会被卖。
- 部署结束后，自动将玩家编队交给游戏原生战术 AI；玩家始终保留主角控制权。
- 自适应野战 AI 按实际战力选择战术；攻城时让危险区内的空闲 AI 士兵规避重型炮弹。
- 可按商队上限和精锐选项自动组建家族商队，并自动选择合适同伴和文化模板。
- 提供完整简体中文文本。
- 不修改单位生命、伤害、武器精度、移动速度或其他战斗数值。

## 安装

需要先安装并启用：

- [Bannerlord.Harmony](https://github.com/BUTR/Bannerlord.Harmony)
- [Bannerlord.UIExtenderEx](https://github.com/BUTR/Bannerlord.UIExtenderEx)

使用打包版本时：

1. 解压文件，将 `Modules/Bannerlord.PartyAI` 复制到游戏目录下的 `Modules` 文件夹。
2. 在启动器中依次启用 `Bannerlord.Harmony`、`Bannerlord.UIExtenderEx` 和 `Bannerlord.PartyAI`。
3. 启动单人游戏并载入存档。

不要同时安装同一模块 ID 的其他 Party AI Controls 版本。旧版（1.x）存档可以直接载入，所有部队、模板、城镇设置都会保留。

## 使用方式

### 控制面板

载入战役存档后按 `Ctrl+P` 打开控制面板。面板是一个全屏页面，顶部五个标签页，左侧列表、右侧编辑器，所有改动即时生效，没有“保存/取消”：

| 标签 | 内容 |
| --- | --- |
| 部队 | 家族部队/商队/王国部队的默认设置、玩家主队、每支可管理部队。右侧编辑命令队列、待机命令、模板、兵种比例、招募、行为和后勤选项；主队条目还包含自动驾驭和进城出售设置。 |
| 领地 | 全局城镇默认设置、驻军默认设置、每座玩家城镇/城堡（城镇管理 + 驻军兵种）以及可管理的王国驻军。 |
| 模板 | 创建、导入、微调、查看和删除兵种模板，显示目标兵种与升级路线上的全部兵种。 |
| 经济 | 家族每日收支明细、财政策略（金币储备、最低日收支、工坊管理与购买模式、购买建议）以及所有玩家工坊的状态与建议。 |
| 设置 | 管理范围、兵种转换、家族自动化、自动进攻、AI 调整、战场选项和快捷键。 |

列表中选中一个条目后可以点“复制设置”（或 `Ctrl+C`），勾选其他兼容条目再“粘贴到已勾选”（或 `Ctrl+V`），批量复制模板、比例、命令、选项或城镇管理设置。

如果快捷键设置错误导致面板无法打开，可在游戏控制台输入：

```text
partyai.open
```

### 财政策略

在“经济”标签页中设置：

- **金币储备**（默认 20000）：建设拨款、自动组建商队、玩家主队升级、玩家出资的兵种转换、工坊转产等一次性支出，都不会让金币低于这个数值。
- **最低日收支**（默认 0）：会增加长期工资的自动化——自动创建家族部队、向驻军捐赠士兵——必须让预计日收支保持在这个数值以上。想持续积累财富就设成正数，允许一定赤字就设成负数。
- 页面顶部显示当前金币、预计每日变化、储备状态，以及与游戏家族界面一致的收支明细，出现赤字或低于储备时会有红色标记。

旧版存档中“玩家保留金币”会自动迁移为新的全局金币储备。

### 工坊管理

“经济”标签页列出所有玩家工坊，显示资本、每日收入、评估周期内的资本变化、是否停工，以及顾问建议。评估依据与游戏 AI 开设工坊时相同：附属村庄的原料供给、本地市场原料价格、产出物价格，以及城内同类工坊的竞争。

- `关闭`：只显示信息。
- `仅推荐`（默认）：工坊在评估周期内资本持续下降且没有收入时，提示更适合的生产类型和转产费用。
- `自动切换`：满足上述条件且金币储备允许时直接转产，同一工坊 30 天内不会重复切换。

任何模式下都可以在面板中手动点击“改为 xxx”或“出售”。转产费用与出售价格与原生游戏一致。

**购买工坊**（“购买工坊”一行）：考察你自己城镇以及主队当前所在城镇里显贵拥有的工坊，只有生产类型在该城评分靠前的才算合格，繁荣度高的城镇加分。“仅推荐”会提示并在“购买建议”行显示；“自动”会在价格不超过储备之上金币的一半、且家族等级允许再拥有一座时买入。也可以随时点“买入”手动购买。

### 主队自动驾驭

在“部队”标签页选中你自己的部队，打开“我不操作时自动驾驭我的部队”。之后：

- 主队像家族部队一样执行自己的命令队列与待机命令。可用命令：巡逻家族领地、在某地周围巡逻、防守（等同于在该地周围巡逻）、招募、前往、驻留、跟随、攻击、围攻（会把你带到城门口，是否围城由你决定）。
- 你在地图上点任何地方都会立即收回控制；部队停下并空闲达到“空闲多久后恢复”（默认 5 秒现实时间）后自动驾驭再接手。暂停游戏时它不会动。
- 开启“允许进入定居点”后，招募和前往命令会把主队带进城镇/村庄，进入时执行定居点自动化（招募、升级、换装），随后自动离开并继续。“驻留于定居点”命令则把访问交还给你。
- 主队也可以使用“兵力不足时自动招募”，低于阈值时自动排入一次招募行程。

### 自动进攻与军团

在“设置”标签页的“进攻”一节开启“自动发起围城”。每天评估一次：

- 候选部队是没有玩家命令（或只在执行待机命令）、没有被派去防守、兵力比例达标、允许围城的家族部队；会保留城镇防御中设定的预备部队数量。你自己的部队永远不会被派出。
- 目标是搜索半径内与你交战的敌方城堡或城镇。防御力 = 驻军 + 民兵 + 城内敌方领主 + 附近敌方领主的一半。当集结部队的战力达到防御力的设定倍数（默认 2 倍）时出发，城镇优先于城堡，防御弱者优先。
- 你的领地正在被围时不会发起进攻；一次只进行一场围城。
- 加入王国并开启“组建军团”后，参战部队合并为一支由最强部队率领的军团（召集自家部队不花影响力，维持凝聚力可能会）；军团解散时改为各自围城。
- 目标攻陷、和谈、目标易主、出现更强的援军、或超过“放弃时限”时自动结束，所有部队恢复原来的命令。也可以随时点“取消”。

### 进城自动出售

在主队条目的“进城事务”里设置。主队进入非敌对、未被围的城镇时：

- **出售俘虏**：卖掉所有非英雄俘虏；开启“保留符合模板的俘虏”后，处于模板升级路线上的俘虏会留下以便招募。在部队界面锁定的俘虏不会被卖。
- **出售武器和护甲**：卖掉物品栏中的武器、护甲和马具；坐骑、食物、书籍、旗帜永远不卖。在物品栏里锁定物品即可保留。开启完全自动化时会先给同伴配装再出售。
- **同时出售贸易品**：默认关闭，手动跑商时保持关闭。

### 定居点自动化

每支领主部队、商队和玩家主队可以分别选择：

- `关闭`：不在进入定居点时执行额外操作。
- `仅招募`：按模板和兵种比例招募当前可用兵员。
- `招募并升级`：在招募后自动使用已有经验、金币和所需物品完成可用升级。
- `完全自动`：再按模板转换不合适的兵种，并用队伍库存为 AI 领主及同队英雄换上更优装备。

普通士兵的装备由兵种定义决定，因此完全自动通过兵种升级树改善其装备，不会修改全局单位数据。主角本人的装备不会被自动替换。

### 城镇管理

城镇管理默认关闭。在“领地”标签页选择“全局默认”并启用；玩家家族拥有的城镇与城堡显示在同一列表中，可分别编辑：

- `均衡`、`稳定`、`经济`、`军事`四种建设策略。
- 建筑队列、每日项目、忠诚与粮食紧急阈值。
- 建设储备目标和每日投入上限（受全局金币储备约束）。
- 总督关闭、仅推荐或自动任命，以及重分配冷却。
- 自动派防、防务优先级、目标防御战力和目标驻军人数。

全局设置是新封地和“跟随全局默认”封地的实时默认值；关闭“跟随全局默认”后，该封地保留自己的独立配置。“把默认设置应用到所有领地”可以一次性让全部封地重新跟随全局默认，同时保留各封地的启用/停用状态。

“经济”策略会按建筑下一等级的实际边际效果与建设成本排序，优先税收、关税、繁荣、工坊、村庄产出和驻军减薪；粮食转为负增长时会提前提高粮食建设权重，忠诚或缺粮进入设定阈值后则暂停普通建设并启用合适的每日项目。单城面板顶部显示管理状态、总督状态和经济概况（繁荣、粮食变化、关税、项目、村庄收入、驻军工资和近似净收益）。

自动派防只使用符合条件的玩家家族部队，不会拆散现有军团，也不会覆盖玩家主动下达的新命令。启用自动补充驻军后，援军抵达安全定居点才会移交士兵，同时遵守最大移交比例、部队最低留兵数，以及新增驻军工资不能把日收支压到财政下限以下。威胁解除且满足最短驻守时间后，系统恢复该部队原有命令与队列。

### 模板

载入战役时会根据当前游戏数据动态生成“全阵营最强”和各主文化最优模板。

“模板”标签页的“在线模板”可导入 HTTPS JSON。格式示例见 [`template.example.json`](template.example.json)：

```json
{
  "name": "Imperial balanced elite",
  "troops": ["imperial_legionary", "imperial_palatine_guard"],
  "composition": {
    "infantry": 55,
    "ranged": 45,
    "cavalry": 0,
    "horseArcher": 0
  }
}
```

比例既可写成 `0-1` 小数，也可写成百分数；导入时会归一化。兵种使用游戏内部 `StringId`，无效 ID、重复名称、非 HTTPS 地址和超过 64 KB 的文件都会被拒绝。

### 大地图直接指挥

- 按 `Alt+X` 选择附近可直接指挥的部队。
- 按住 `Alt`，在地图上向已选择部队下达移动或目标命令。
- 快捷键可在“设置”标签页修改。

### 战场 AI 指挥官

- “自动战场指挥官”默认开启：完成部署并正式开战后，AI 自动接管我方所有可指挥编队，你仍然控制主角。
- 按 `Ctrl+M` 收回编队指挥权；再次按下重新交给 AI。
- “自适应野战 AI”根据双方剩余战力、远程比例和兵种构成参与战术选择，开战提示显示按兵阶、装备和单位战斗力估算的实际比例。
- “规避攻城火炮”只处理投石机等重型范围弹药，不会打断正在近战、攀爬或操作攻城器械的士兵。

### 自动商队与自动部队

- 启用“自动组建家族商队”后，玩家主队停留在安全城镇时每天最多建立一支商队，直到达到上限；费用与原生一致，且不会突破金币储备。
- 启用“自动创建家族部队”后，只有当金币高于储备、且预计日收支能承担一支新部队的平均工资时才会组建。

## 代码结构

```text
Bannerlord.PartyAI/
  PartyAi.cs                 战役期服务的统一入口（Settings / Parties / Towns / Defense / Offense / Workshops / Sales / Autopilot / DirectCommand）
  SubModule.cs               模块生命周期：补丁、行为注册、快捷键
  Core/                      ModSettings、Hotkey、本地化辅助 L、通知 Notify、存档类型定义
  Finance/                   Treasury（金币储备 / 日收支门槛）、WorkshopAdvisor、WorkshopManagementBehavior、TownSalesBehavior
  Parties/                   PartyProfile、PartyRegistry、命令系统 Orders/、招募与转换 Recruitment/、模板 Templates/、主队自动驾驭 Autopilot/
  War/                       OffenseBehavior（机会进攻、军团组建）
  Towns/                     城镇管理、自动防御、驻军移交
  Battle/                    战场指挥官、自适应战术、攻城火炮规避
  GameModels/                替换的游戏模型（升级、军团、俘虏招募、买粮）
  Patches/                   Harmony 补丁，统一在 PatchSet 中注册
  UI/                        ControlPanelScreen/VM、Pages/（五个标签页）、Detail/（右侧编辑器）、Components/（通用行控件）、Dialogs/
  _Module/GUI/Prefabs/       Gauntlet 界面 XML（PartyAi*.xml）
```

存档兼容通过保留 `SaveableTypeDefiner` 的数字 ID、`SaveableProperty` 索引、行为 `StringId` 和 `SyncData` 键实现；类名可以随意重命名。

## 兼容性说明

- 当前分支只针对游戏 `v1.5.2` 编译和验证。
- 战场接管只用于单人任务，不会在多人会话中加载。
- 此分支沿用原模块 ID `Bannerlord.PartyAI`，可覆盖更新原版，但不要并列安装两个版本。
